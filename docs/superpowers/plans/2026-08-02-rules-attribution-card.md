**Goal:** Put an ever-present card on every rules page thanking Josh McCrowell for the open license and linking to where the book can be bought, and align the project's spelling of "license" with his.

**Architecture:** One new presentational Svelte component with no props, wrapped in the existing `OrnamentalBorder`, rendered as the last element of both rules routes. Plus a mechanical spelling change across prose files. No game data changes, no server changes, no schema changes.

**Tech Stack:** SvelteKit 2 + Svelte 5 (runes mode), TypeScript strict, Playwright for E2E.

## Global Constraints

- **Never alter the license-required disclaimer.** The "Adherent of the Worm"
  license mandates this exact statement: "His Majesty the Worm is copyright
  Joshua McCrowell. [product name] is an independent production by [publisher
  name] and is not affiliated with Joshua McCrowell or Exalted Funeral." It
  currently appears, correctly filled in, in `src/routes/+layout.svelte`,
  `src/routes/licensing/+page.svelte`, `src/lib/export/markdown-export.ts`,
  `src/lib/export/pdf-export.ts`, and `src/lib/export/denizen-pdf-export.ts`.
  **None of those five strings may change in this plan.** The new card is
  additive; it never replaces the disclaimer.
- **Book title is set "His Majesty the Worm"** — lowercase *the*. Never "His
  Majesty The Worm".
- **The two external URLs are exact.** No trailing slash, no tracking
  parameters, no `http://`:
  - `https://www.hismajestytheworm.games/open-license`
  - `https://www.hismajestytheworm.games/his-majesty-the-worm`
- **External links carry `target="_blank" rel="noopener"`**, matching the
  existing links on `src/routes/licensing/+page.svelte`.
- **No horizontal overflow at 320 CSS pixels or at 200% zoom.** This is a
  standing constraint in this layout — see the comments on `.site-nav` in
  `src/routes/+layout.svelte` and on `.alpha-banner` in
  `src/lib/components/layout/AlphaBanner.svelte` for why it was made one.
- **Svelte 5 runes only.** `$props()` with destructuring, `$state`, `$derived`.
  No `export let`, no stores in components.
- **No automated-authorship attribution in commits.** No "generated by"
  footers, no co-author trailers. (`CLAUDE.md`, Publishing.)
- **Branch, don't push to `main`.** Work happens on
  `feat/rules-attribution-card`, which already exists and already carries the
  design doc commit.

**Background for whoever implements this:** `/rules` renders one of three
mutually exclusive things inside its `<section class="rules">` — search results,
a "no rules match" message, or the chapter table of contents. All three are
inside a single `{#if query.trim() && hits} … {:else} … {/if}` block that ends
at line 116. The card must go *after* that closing `{/if}`, still inside the
`<section>`. Putting it inside either branch would make it vanish on the other
states, which defeats the point of the feature.

- [ ] **Step 1: Write the failing E2E test**

Create `tests/e2e/rules-attribution.spec.ts`:

```ts
import { expect, test } from '@playwright/test';

const LICENSE_URL = 'https://www.hismajestytheworm.games/open-license';
const PURCHASE_URL = 'https://www.hismajestytheworm.games/his-majesty-the-worm';

test.describe('rulebook attribution card', () => {
	test('is on the rules index with both links intact', async ({ page }) => {
		await page.goto('/rules');
		const card = page.getByTestId('rulebook-thanks');
		await expect(card).toBeVisible();
		await expect(
			card.getByRole('heading', { name: 'With thanks to Josh McCrowell' })
		).toBeVisible();
		// The two hrefs are the assertions that matter: copy drift is cosmetic,
		// but a broken purchase link is the one failure with a real cost, and it
		// is exactly what a careless find-and-replace breaks silently.
		await expect(card.getByRole('link', { name: 'licensed the game' })).toHaveAttribute(
			'href',
			LICENSE_URL
		);
		await expect(card.getByRole('link', { name: 'His Majesty the Worm' })).toHaveAttribute(
			'href',
			PURCHASE_URL
		);
	});

	test('is on a chapter page', async ({ page }) => {
		await page.goto('/rules/city-phase');
		const card = page.getByTestId('rulebook-thanks');
		await expect(card).toBeVisible();
		await expect(card.getByRole('link', { name: 'His Majesty the Worm' })).toHaveAttribute(
			'href',
			PURCHASE_URL
		);
	});

	test('survives the empty-search state', async ({ page }) => {
		// The index swaps its whole body between results, "no match", and the
		// TOC. The card lives outside that switch and must show on all three.
		await page.goto('/rules?q=zzzznotarule');
		await expect(page.getByText('No rules match')).toBeVisible();
		await expect(page.getByTestId('rulebook-thanks')).toBeVisible();
	});

	test('opens both links in a new tab, safely', async ({ page }) => {
		await page.goto('/rules');
		const card = page.getByTestId('rulebook-thanks');
		for (const name of ['licensed the game', 'His Majesty the Worm']) {
			const link = card.getByRole('link', { name });
			await expect(link).toHaveAttribute('target', '_blank');
			await expect(link).toHaveAttribute('rel', /noopener/);
		}
	});
});
```

Two notes on the markup. The `>licensed the game</a\n>` line breaks are
Prettier's doing — it hugs the tags to stop stray whitespace appearing inside
the link text, and `npm run format` will reformat it that way regardless.
Second, `.cta` needs `!important` on its margin only because `.thanks p` sets a
bottom margin on every paragraph and both selectors have equal specificity; if
you prefer, restructure to `.thanks p:not(.cta)` instead and drop the
`!important`. Either is fine — don't leave both.
